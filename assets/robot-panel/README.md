# 로봇 제어 패널

메인 `index.html`의 단일 버튼으로 같은 사이트 안에 열린다. 기존 공정 UI/백엔드/API는 유지한다. `host_on` 실행 시 사용하는 8082 사이트와 개발 미리보기에서 같은 정적 파일을 사용한다.

- 영상은 받지 않는다. 카메라는 로봇 안의 도킹 비전 전용이다(로봇 docking.yaml `vision.preview_enabled: false`, 8085 영상 서버 없음).
- 작은 상태/Action: 같은 PC의 rosbridge 9090. `/M1/data`와 `/M2/data`를 각각 사용한다.
- 화면 진입은 구독만 한다. 실제 이동은 사용자의 목적지 버튼 클릭에만 요청한다.
- 최신 제어 상태가 없거나 임무/명령이 진행 중이면 새로운 목적지를 막는다. 정지 버튼은 연결이 살아 있는 동안 사용 가능하다.
- 연결 복구 시 명령을 자동 재전송하지 않는다. 닫기는 통신을 해제하며 로봇 작업을 취소하지 않는다.
- `(최근 기록)`은 저장된 마지막 임무 결과다. 현재 위치를 단정하지 않는다.
- 화면 디버깅은 상태 데이터/Action 결과이며 전체 journal 텍스트를 전송하는 기능은 아니다.

검사: `node tests/robot-panel.test.cjs` (실제 로봇 이동 없음).
