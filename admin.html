적용 범위

이 페이지는 공개된 시뮬레이션 설정 도구입니다. 실제 로봇 속도를 제어하지 않습니다. 저장값은 이 브라우저에만 보관되며 다음 새 주문부터 적용됩니다. 전진·후진 속도는 기존 이동 대비 배율로, 실제 m/s가 아닙니다.

Host 통신 모드에서는 서버 설정을 사용합니다. 아래 유지보수 안내를 확인하세요.

PREVIEW · A제품 2개

예상 소요 시간 —

주행 속도를 바꾸면 예상 시간이 갱신됩니다. 공정 시간은 현재 설정값을 사용하며 실제 장비의 소요 시간을 보장하지 않습니다.

config 파일로 유지보수하기

공정 작업 시간은 관리자 화면에서 조절하지 않습니다. 필요하면 config.js의 process 값을 직접 수정하세요. 기존 브라우저 저장값과 가져온 JSON의 공정 시간은 속도 설정을 저장하거나 내보낼 때 유지됩니다.

  1. 값을 조절하고 config.js 내보내기를 누릅니다. 내보내기는 브라우저 저장과 별개입니다.
  2. 프로젝트 루트의 config.js를 다운로드한 파일로 교체합니다. 브라우저 저장값이 있다면 기본값으로 복원해야 새 파일의 값이 적용됩니다.
  3. GitHub에 반영하면 공개 사이트의 기본 설정이 바뀝니다. 관리자 페이지 저장만으로 공개 파일이 수정되지는 않습니다.

Host PC에 적용

서버를 종료한 뒤 아래 명령으로 새 설정에 맞는 단계 시간표를 생성하고 다시 실행하세요. 생성에는 Node.js, 서버 실행에는 Python 3가 필요합니다. 실행 중인 주문에는 설정을 바꾸지 않습니다.

node host/build_scenarios.cjs
python3 host/server.py

Host 모드에서는 서버가 전달한 설정으로 화면과 완료 ACK 시간을 맞춥니다. 브라우저 개인 설정은 Host 주문에 적용되지 않습니다.
