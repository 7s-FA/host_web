다운로드 안내

하려는 작업에 맞는 파일 하나부터 선택하세요. 웹 시뮬레이션만 볼 때는 다운로드가 필요 없습니다. 실장치 관제 화면은 Host 관제에서 엽니다.

01 · 처음 시작

내 PC에서 Host 통신을 시험하려면

팀 개발 패키지를 받아 압축을 풉니다. robot3_host/ 폴더에서 터미널을 열고 아래 명령을 실행하세요.

python3 web/host/server.py

브라우저에서 http://127.0.0.1:8082/?host=1을 열고 주문을 시작합니다. Python 3.10 이상이 필요합니다.

압축을 풀면

README.md가 시작 안내입니다. web/에는 지금 실행 가능한 시뮬레이션·HTTP 시험이, robot3_*/ 폴더에는 팀별 ROS 2 개발 명세가 있습니다.

현재 패키지는 실제 로봇을 움직이지 않습니다. ROS 2 Action 실행부는 팀에서 구현해야 합니다.

02 · 설정 파일

바꾸려는 값에 맞춰 선택하세요

주문 · 장치 통신

system-config.json

주문 수량, Host 포트, ROS 2 주소·명령·완료 조건을 정리한 파일입니다. 현재는 주문·HTTP 설정 일부가 연결돼 있고 ROS 2 항목은 구현 계약입니다.

ZIP 안의 위치: config/system-config.json

  1. 파일을 수정합니다.
  2. ZIP의 robot3_host/에서 python3 web/host/system_config.py --write-web-policy를 실행하고 서버를 재시작합니다.
기본 JSON 받기 ↓
버거 속도 · 시뮬레이션 시간

config.js

버거 1·2 속도와 시뮬레이션 공정 시간의 기본값입니다. 속도는 관리자 화면에서 조절할 수 있고, 공정 시간은 파일의 process에서 수정합니다.

ZIP 안의 위치: web/config.js

  1. 기본 파일을 수정하거나 관리자에서 새 config.js를 내보냅니다.
  2. ZIP의 robot3_host/에서 node web/host/build_scenarios.cjs를 실행하고 서버를 재시작합니다. 생성에는 Node.js 22 이상이 필요합니다.
현재 기본 파일 받기 ↓속도 조절·내보내기 ↗
버거 1 · 시뮬레이션 경유점

waypoints-burger1.json

Confluence에 정리된 버거 1의 경유·회전 지점 4개와 yaw·전진 모드를 담았습니다. 목적지별 경유 순서와 도면은 웨이포인트 화면에서 확인합니다. 버거 2의 좌표는 포함하지 않습니다.

ZIP 안의 위치: web/waypoints-burger1.json

03 · 개인 자료

백업과 기록이 필요하면

설정 JSON 백업

관리자 화면의 JSON 백업은 내 브라우저 설정을 보관하는 용도입니다. 같은 화면의 JSON 가져오기로 다시 불러올 수 있습니다. 공개 사이트나 Host 서버 설정은 바뀌지 않습니다.
