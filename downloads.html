GET STARTED

다운로드 · 사용법

공개 사이트에서 공정을 확인하고, Host PC에서 이동 로봇을 개별 제어합니다. A제품/B제품과 수량 1개/2개를 버튼으로 선택합니다.

01 · Host PC 실행

웹 서버와 rosbridge를 한 번에

전체 저장소를 ~/host_web에 clone하고 README의 최초 준비를 마친 뒤 실행하세요.

cd ~/host_web
bash start_host.sh

Host PC 브라우저에서 http://localhost:8082/에 접속합니다. 상단 실물 상태 보기 또는 http://localhost:8082/?live=1에서 M1·M2 위치와 로봇팔 상태를 확인합니다. 터미널은 켜 두고, 종료할 때 Ctrl+C를 누릅니다.

실물 상태 모니터링은 수신 전용입니다. 메인 화면과 Host 관제에서 M1·M2의 정지·정지 해제를 요청하고 배터리도 확인할 수 있습니다. 실제 주문은 기존 Host 프로그램에서 실행하고 목적지 이동은 로봇 제어 패널을 사용합니다.

최초 준비·전체 소스 보기 ↗HTTP 시험 ZIP 안내 ↓
최초 준비와 로봇 준비

Host에는 ROS 2 Jazzy, rosbridge와 host_backend/install_local의 Action 타입 빌드가 필요합니다. 자세한 명령은 저장소 README에 있습니다.

각 이동 로봇은 Pi에서 host-ready 준비를 마쳐야 합니다. 통합 실행은 웹·rosbridge를 켜며, 이동 로봇 준비와 전체 자동 공정은 별도입니다.

아래 HTTP 시험 ZIP에는 통합 실행 스크립트가 없습니다. 실제 Host 실행에는 Git으로 받은 전체 소스를 사용하세요.

02 · 화면 사용법

주문과 단계별 실행, 로봇 제어

공정 시뮬레이션

1개 또는 2개 주문

  1. 메인 화면에서 A제품/B제품과 수량 1개/2개 버튼을 선택합니다. 버튼 아래에서 선택 내용을 확인하세요.
  2. 주문 · 시작을 눌러 공정을 재생합니다. 운송 잔여·완제품 잔여·적재 완료 카운트를 확인하세요.
  3. 제품·수량을 바꾸어 다시 시작하려면 초기화를 누릅니다. 완료 후에는 새 주문을 넣을 수 있습니다.

지도와 카운트는 시뮬레이션입니다. A·B제품은 같은 설명용 이동 경로와 고정된 공정 시간을 사용하며, 실제 B제품의 동작·시간을 재현하는 것은 아닙니다.

시뮬레이션 열기 ↗
작업 완료 지점에서 확인

단계별 실행

  1. 제품·수량을 선택하고 단계별 실행을 누릅니다.
  2. 목적지 이동이나 작업이 끝나면 다음 단계 전환 조건을 확인합니다. 빨강은 미완료, 초록은 완료입니다.
  3. 다음 단계 실행으로 이어갑니다. 회전·주행 중간에는 추가 승인이 필요하지 않습니다.

HTTP 시험에서는 Host가 웹의 완료 회신을 확인합니다. 실제 센서나 로봇의 완료 신호를 뜻하지 않습니다.

단계별 공정 확인 ↗
Host PC · 실제 이동 로봇

M1·M2 개별 제어

  1. Host PC의 로컬 화면에서 상단 로봇 제어 ↗를 누릅니다.
  2. ROS 연결과 해당 이동 로봇의 최신 상태 수신을 확인합니다.
  3. 이동할 로봇의 목적지 버튼을 눌러 요청하고, 임무 결과를 확인합니다.

목적지 버튼은 실제 이동을 요청합니다. 메인 화면의 시뮬레이션·실물 상태 보기와 Host 관제에서도 M1 정지·M2 정지를 사용할 수 있습니다. 선택한 로봇만 정지하며 Host 전체 주문이나 다른 로봇·팔을 멈추지 않습니다.

최종 성공 응답이 와야 정지 확인입니다. 10초 안에 결과가 없거나 오류·연결 끊김이 발생하면 정지 여부 미확인이며, 재연결해도 자동 재전송하거나 정지를 해제하지 않습니다. 창 닫기·서버 종료도 정지 명령이 아니므로 먼저 결과를 확인하세요.

M1 정지 해제·M2 정지 해제는 해당 로봇의 최신 상태를 받고 실행 중 임무·대기 요청이 없을 때 누를 수 있습니다. 로봇이 실제 정지를 확인한 뒤 보내는 성공 응답을 확인하세요. 해제는 이전 이동을 재개하지 않지만, 실행 중인 Host 자동 공정이 새 이동을 요청할 수 있으므로 Host 상태를 먼저 확인하세요.

연결·실행 준비 확인 ↗
상태와 기록

실제 상태·기록·Host 관제

장치 연결 표시등은 Host·M1·M2·자재창고·제작공정 연결을 확인합니다. 초록은 연결됨, 노랑은 일부 연결·확인 불가, 빨강은 연결 끊김입니다. Host PC의 로컬 화면에서 사용하며 공개 사이트에서는 회색으로 안내합니다. 제작공정은 로봇팔 2·3 제어 서버 기준으로, 리니어·카메라 개별 정상이나 공정 완료를 뜻하지 않습니다.

실물 상태 보기는 받은 좌표와 방향, 로봇팔의 작업 상태를 표시합니다. 첫 좌표 전에는 아이콘을 숨기고 3초 이상 오래되면 흐리게 표시하며 화면의 아이콘 움직임을 멈춥니다. 로봇팔 상태를 확인하지 못하면 애니메이션도 멈춥니다. Host와 로봇의 시각을 동기화하세요. 작업 시작 전에 이 화면을 열어 두세요. 도중에 새로 열면 팔 상태 피드백을 받을 때까지 상태 미확인으로 표시합니다.

메인 시뮬레이션·실물 보기·Host 관제·로봇 제어 패널에 M1·M2의 배터리 전압과 추정 잔량을 표시합니다. 실제 전압의 10.5~12.3V 범위를 0~100%로 환산한 추정치입니다. 5초 이상 새 값이 없거나 연결이 끊기면 마지막 값임을 표시하고, 첫 수신 전·비정상 값은 미확인으로 표시합니다. 공개 사이트에서는 로컬 연결을 안내합니다.

상세·기록 → 기록 내려받기에서 현재 시점까지의 시뮬레이션 이벤트·카운트를 저장할 수 있습니다. 웨이포인트 화면에서는 경유 순서와 좌표를 확인합니다.

Host 관제에서는 A제품/B제품과 수량 1개/2개를 버튼으로 선택합니다. 통신 상태는 M1·M2·자재창고·제작공정 네 단위로 확인하며, 제작공정에는 로봇팔 2·3, 리니어와 카메라가 포함됩니다.

각 장치와 Host의 로그 버튼으로 작은 팝업을 엽니다. 통신이 끊겨도 마지막 기록을 확인할 수 있습니다. Host 어댑터가 연결되지 않으면 주문·다음 단계 버튼은 비활성화됩니다. M1 정지·M2 정지는 HTTP의 localhost·127.0.0.1 화면에서 rosbridge가 연결되면 사용할 수 있습니다. Host 어댑터 미연결·처리 중·오래된 상태 보고와 관계없이 정지를 요청할 수 있고, 로봇별 대기와 결과를 따로 표시합니다. 공개 사이트에서는 정지·해제 버튼이 비활성화됩니다. 메인 시뮬레이션도 같은 A제품/B제품·1개/2개 버튼을 사용합니다. 목적지 이동은 별도 로봇 제어 패널을 사용합니다.

03 · 다운로드와 업데이트

시험 패키지와 최신 코드 사용

HTTP 시험 패키지

Python 3.10 이상으로 웹·Host 간 명령과 완료 회신을 시험합니다. ZIP을 풀고 robot3_host/에서 아래 명령을 실행하세요.

python3 web/host/server.py

http://127.0.0.1:8082/?host=1에서 주문합니다. ZIP의 ROS 폴더는 팀 개발 명세이며, Python 서버만으로 로봇 제어 연결이 준비되지는 않습니다.

HTTP 시험 패키지 받기 ↓

변경한 코드가 안 보일 때

  1. 이동 중인 로봇은 패널에서 정지 결과를 확인하고, 기존 서버를 Ctrl+C로 종료합니다.
  2. Host의 ~/host_web에서 git pull --ff-only origin main을 실행합니다.
  3. bash start_host.sh로 다시 켜고 브라우저에서 Ctrl+Shift+R을 누릅니다.

HTTP 시험 ZIP은 최신 파일을 새 폴더에 풀고 서버를 다시 실행하세요. 공개 사이트는 GitHub Pages 배포가 끝난 뒤 새로고침합니다.
