GET STARTED

다운로드 · 사용법

공개 사이트에서 공정을 확인하고, Host PC에서 버거를 개별 제어합니다. 주문 수량은 1개 또는 2개입니다.

01 · Host PC 실행

웹 서버와 rosbridge를 한 번에

전체 저장소를 ~/host_web에 clone하고 README의 최초 준비를 마친 뒤 실행하세요.

cd ~/host_web
bash start_host.sh

Host PC 브라우저에서 http://localhost:8082/에 접속합니다. 터미널은 켜 두고, 종료할 때 Ctrl+C를 누릅니다.

최초 준비·전체 소스 보기 ↗HTTP 시험 ZIP 안내 ↓
최초 준비와 로봇 준비

Host에는 ROS 2 Jazzy, rosbridge와 host_backend/install_local의 Action 타입 빌드가 필요합니다. 자세한 명령은 저장소 README에 있습니다.

각 버거는 Pi에서 host-ready 준비를 마쳐야 합니다. 통합 실행은 웹·rosbridge를 켜며, 버거 준비와 전체 자동 공정은 별도입니다.

아래 HTTP 시험 ZIP에는 통합 실행 스크립트가 없습니다. 실제 Host 실행에는 Git으로 받은 전체 소스를 사용하세요.

02 · 화면 사용법

주문과 단계별 실행, 로봇 제어

공정 시뮬레이션

1개 또는 2개 주문

  1. 메인 화면에서 A제품 수량을 1 또는 2로 정합니다.
  2. 주문 · 시작을 눌러 공정을 재생합니다. 운송 잔여·완제품 잔여·적재 완료 카운트를 확인하세요.
  3. 수량을 바꾸어 다시 시작하려면 초기화를 누릅니다. 완료 후에는 새 주문을 넣을 수 있습니다.

지도와 카운트는 시뮬레이션입니다. 주행과 공정 시간은 고정값을 사용합니다.

시뮬레이션 열기 ↗
작업 완료 지점에서 확인

단계별 실행

  1. 수량을 정하고 단계별 실행을 누릅니다.
  2. 목적지 이동이나 작업이 끝나면 다음 단계 전환 조건을 확인합니다. 빨강은 미완료, 초록은 완료입니다.
  3. 다음 단계 실행으로 이어갑니다. 회전·주행 중간에는 추가 승인이 필요하지 않습니다.

HTTP 시험에서는 Host가 웹의 완료 회신을 확인합니다. 실제 센서나 로봇의 완료 신호를 뜻하지 않습니다.

단계별 공정 확인 ↗
Host PC · 실제 버거

버거 1·2 개별 제어

  1. Host PC의 로컬 화면에서 상단 로봇 제어 ↗를 누릅니다.
  2. ROS 연결과 해당 버거의 최신 상태 수신을 확인합니다.
  3. 이동할 버거의 목적지 버튼을 눌러 요청하고, 임무 결과를 확인합니다.

목적지 버튼은 실제 이동을 요청합니다. 창 닫기·서버 종료는 로봇 정지 명령이 아니므로, 이동 중에는 패널에서 정지 결과를 먼저 확인하세요.

연결·실행 준비 확인 ↗
상태와 기록

공정 기록·Host 관제

상세·기록 → 기록 내려받기에서 현재 시점까지의 시뮬레이션 이벤트·카운트를 저장할 수 있습니다. 웨이포인트 화면에서는 경유 순서와 좌표를 확인합니다.

Host 관제는 전체 공정용 Host 어댑터의 보고 상태를 표시합니다. 어댑터가 연결되지 않으면 주문·다음 단계 버튼이 비활성화됩니다. 버거 개별 제어 패널과는 별도입니다.

03 · 다운로드와 업데이트

시험 패키지와 최신 코드 사용

HTTP 시험 패키지

Python 3.10 이상으로 웹·Host 간 명령과 완료 회신을 시험합니다. ZIP을 풀고 robot3_host/에서 아래 명령을 실행하세요.

python3 web/host/server.py

http://127.0.0.1:8082/?host=1에서 주문합니다. ZIP의 ROS 폴더는 팀 개발 명세이며, Python 서버만으로 로봇 제어 연결이 준비되지는 않습니다.

HTTP 시험 패키지 받기 ↓

변경한 코드가 안 보일 때

  1. 이동 중인 버거는 패널에서 정지 결과를 확인하고, 기존 서버를 Ctrl+C로 종료합니다.
  2. Host의 ~/host_web에서 git pull --ff-only origin main을 실행합니다.
  3. bash start_host.sh로 다시 켜고 브라우저에서 Ctrl+Shift+R을 누릅니다.

HTTP 시험 ZIP은 최신 파일을 새 폴더에 풀고 서버를 다시 실행하세요. 공개 사이트는 GitHub Pages 배포가 끝난 뒤 새로고침합니다.

저장소에서 최신 버전 확인 ↗

공개 사이트의 공정 지도는 시뮬레이션입니다. 실제 버거 개별 제어는 준비된 로봇과 rosbridge가 연결된 Host PC의 로컬 화면에서 사용하세요.
