# 팀 통합 시험·인수 기준

상태: 아래 시험의 ROS 자동화 코드는 팀 구현 대상입니다. 현재 패키지는 실물 시험 통과를 의미하지 않습니다.

| 시험 | 기대 결과 |
| --- | --- |
| 주문 1개 | B1 운송·조립·적재·복귀, B2 초기위치 유지 |
| 주문 2개 | B1 창고 도착 시 B2 대기 출발, 교대·복귀 순서 유지 |
| 주문 3개 | 제품별 조건·담당 버거 교대와 카운트 정상 |
| 수량 범위 밖 | 웹·Host 모두 주문 거부 |
| Goal 수락만 수신 | 완료 표시·다음 공정 시작 금지 |
| Feedback 100%만 수신 | Result 전까지 완료 금지 |
| IR/도킹 실패 | 버거 완료 금지, 팔 적재/조립 시작 보류 |
| 적재 2개 또는 팔 미이탈 | LOAD_PARTS 성공 판정 금지 |
| 중복 완료/STARTED | 카운트 한 번만 변경 |
| 잘못된 주문·작업·attempt·boot | 현재 완료 조건에 반영 금지 |
| heartbeat/결과 timeout | 관련 작업 진행 보류, 재접속 후 상태 조회 |
| 팔3 동시 요청 | 리니어와 팔 동시 구동 금지 |
| 다음 단계 버튼 연속 클릭 | 동일 작업 중복 실행 금지 |
| 브라우저 새로고침 | Host 실제 상태 복원, 주문 중복 생성 금지 |
| 최종 완료 | 제품 적재·운송 도착·두 버거 HOME·팔/리니어 종료 모두 필요 |

순서: mock 자동 시험 → 비구동 보드 통신 → 장치 단독 → 제품1개 → 제품2개. 결과에 config 버전, 주문/작업 ID, 장치 boot ID, 시간, 실제 기대/관측 결과를 남기세요.

실제 보드로 교체할 때는 [실물 전환 안내](../REAL_ROBOT_SETUP.md)를 함께 확인하세요.
