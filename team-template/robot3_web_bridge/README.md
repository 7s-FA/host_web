# 웹 연결 담당

상태: 구현 필요. 기존 HTML/CSS·주문·카운트 UI는 web/에 제공됩니다.

- 웹 → Host: 주문 제출, 자동/단계별 모드, 다음 작업 요청, 일시정지/재개 요청, 상태 조회.
- Host → 웹: 주문 ID, 카운트, 장치 연결/작업 상태, 선행 조건별 완료·미완료·오류 이유, 로그.
- ROS 콜백을 브라우저에 전달할 HTTP/WebSocket 브리지를 구현합니다. 통신 방식·API와 동시 접속 제어권을 Host 담당과 먼저 합의하세요.
- 실제 모드에서는 engine.js의 경과시간이나 웹 ACK를 실제 장치 완료로 처리하지 않습니다.
- 실제 위치를 표시하려면 각 버거 위치/지도 좌표 변환을 별도로 정의합니다. 시뮬레이션 픽셀 좌표를 실제 위치로 표시하지 않습니다.
- 연결 끊김에는 상태를 '확인 불가'로 표시하며 마지막 값을 최신으로 오인하지 않도록 합니다.
- 관리자 설정은 적용 범위·버전을 표시하고 진행 중 작업 설정을 임의 변경하지 않습니다.

제출물: API 명세·브리지 노드·웹 수정. 합격: Host가 받은 결과로만 색상/카운트가 변경되고 새로고침 후 Host 상태가 복원됨. 단계별 실행이 불충족 조건을 우회하지 못함.

실제 보드로 교체할 때는 [실물 전환 안내](../REAL_ROBOT_SETUP.md)를 함께 확인하세요.
