# 기존 웹·HTTP 시험 프로그램

이 폴더에는 패키징 시 기존 웹·사진·설정·HTTP Host 코드가 복사됩니다. 루트에서 python3 web/host/server.py로 실행합니다. 실제 ROS 장치 제어가 아니라 기존 시뮬레이션 시험이며, 관제 전환 작업은 ../robot3_web_bridge/README.md를 참고하세요.

실장치 관제 화면은 `control.html`이며 `HOST_CONTROL_GUIDE.md`에 로컬 Host 상태·명령 API 계약을 정리했습니다. 장치 결과를 검증하는 ROS 2 어댑터는 별도 구현해야 합니다.
